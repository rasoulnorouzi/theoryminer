## Where the files come from

1. The PLOS ONE files come from the PLOS "printable" PDF link.
2. The Frontiers file comes from the Frontiers PDF link.
3. The BMC Public Health files and the Social Indicators Research file come from the PMC Open Access
   data set (`pmc-oa-opendata` on AWS). The publisher sites block automatic downloads.

Each file is the publisher version of the article. Each PDF has a text layer.
